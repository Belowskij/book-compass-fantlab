# Книжный компас

Мобильный навигатор по книгам на русском языке. Источник библиографии, аннотаций, обложек и рейтингов — [ФантЛаб](https://fantlab.ru). Не читалка и не магазин.

## Запуск

Node.js 22.12+ (на Vercel используется 24.x).

```sh
npm ci
npm run dev
```

В режиме разработки Vite подключает тот же серверный обработчик, что используется функцией Vercel. Ключи API и база данных не нужны.

```sh
npm test
npm run build
```

Браузерная проверка с настоящим API (Chromium должен быть установлен): `node scripts/check-browser.mjs`. Для опубликованного сайта задайте `BASE_URL`. Путь браузера в скрипте можно адаптировать к своему компьютеру. Проверка продолжений, группировки, фильтров и мобильного шрифта: `node scripts/check-discovery.mjs`. Проверка массовых статусов циклов и миграции: `node scripts/check-cycle-status.mjs` (также поддерживает `BASE_URL`).

## Первая версия

- Поиск произведений и авторов с пагинацией, настоящими обложками и рейтингами.
- Карточка книги, аннотация, цепочки родительских циклов, состав произведения, похожие книги, ссылка на ФантЛаб.
- Вложенные циклы: порядок массива `children` и уровни `deep` сохраняются. Даты публикации для упорядочивания не используются.
- Следующее чтение: первая непрочитанная опубликованная работа в библиографии цикла. Вложенные циклы раскрываются в общем порядке; части уже включённого романа не становятся отдельными следующими томами. Пропуски перед прочитанными книгами отмечаются отдельно.
- Отметка всего цикла прочитанным добавляет отдельные опубликованные произведения, включая подциклы, без дублей и записей циклов как книг. Старые и импортированные записи прочитанных циклов автоматически разворачиваются; более поздние индивидуальные статусы сохраняются. При ошибке состава библиотека не меняется.
- Текущему чтению отдан приоритет: для книги «Читаю» предлагается следующая непрочитанная после неё; более ранние пропуски не перехватывают эту подсказку. Пустые ссылки API вида `[{}]` не считаются циклами.
- Для похожих произведений книги группируются по циклу; у самостоятельного произведения остаётся собственная карточка. Источник можно искать по названию цикла или его книг. В списке сначала показываются шесть вариантов, затем можно раскрыть остальные. Похожие книги и циклы запрашиваются через официальный `/work/{id}/similars`, без новой выдуманной семантической модели.
- Фильтры поиска действуют на текущую страницу (до 25 результатов): цикл/не цикл, жанры из `classificatory.genre_group` (раздел 1), объём до 250 / 251–500 / более 500 страниц. Для объёма выбирается отдельное бумажное русское издание с совпадающим названием, его страницы и ссылка показываются в карточке. Для циклов страницы не суммируются. Данные уточняются по запросу при открытии фильтров; недоступные карточки не выдаются за проверенные. Времени чтения в API нет.
- В продолжениях нет демонстрационных книг: подсказки основаны только на прочитанных произведениях пользователя. Каждая подсказка показывает, какие книги цикла уже прочитаны.
- Библиотека: «Не читал», «Читаю», «Прочитано», «Хочу прочитать», удаление с отменой, фильтры, JSON-экспорт и импорт с проверкой структуры.
- PWA: манифест, значки, service worker и кэш оболочки приложения. На iPhone: Safari → Поделиться → На экран «Домой».

## Официальный API

Документация: https://github.com/FantLab/FantLab-API. Проверены реальные ответы 22 октября 2026 года.

Используем только документированные GET-запросы:

- `/search-works?q=…&page=…`
- `/search-autors?q=…&page=…`
- `/search-ids?w=…` и `/search-ids?a=…`
- `/work/{id}/extended`
- `/work/{id}/similars`
- `/autor/{id}/extended`

Серверный прокси `api/fantlab.ts` разрешает только эти операции и проверяет параметры. `server/fantlab.ts` нормализует ответы, обрабатывает отсутствующие поля и ошибки. Таймаут отдельного запроса — 18 секунд. Есть дедупликация запросов, ограниченный кэш процесса (до 200 записей), CDN-кэш Vercel (1 час + stale-while-revalidate) и кэш клиента (5 минут). Полная база не копируется. API ещё меняется; внешние ошибки показываются пользователю с повтором.

## Ограничения

- Порядок библиографии не гарантирует внутреннюю хронологию. Мы явно указываем это в интерфейсе.
- API не предоставляет надёжную полную карту персонажей, продолжений их историй и связей вселенных. Показываем только доступные цепочки циклов и состав произведения, не выдумываем отношения.
- Похожие произведения — рекомендации сообщества ФантЛаба, не подтверждение общей вселенной и не персональная модель оценок.
- За один проход проверяются до 12 книг со статусом «Читаю» или «Прочитано» (текущие в первую очередь) и до 8 циклов. Ограничение показывается в интерфейсе, если оно применяется.
- Пустые и ошибочные ответы не заменяются фиктивными данными. При отсутствии обложки выводится нейтральная типографская карточка.
- Данные библиотеки находятся только в localStorage браузера, без аккаунта и синхронизации. Очистка данных Safari удалит библиотеку. Регулярно экспортируйте JSON; импорт объединяет списки, а совпавшие записи получает из файла.
- Без интернета доступна оболочка и сохранённая библиотека. Поиск, новые карточки и рекомендации требуют сети.

## Размещение

Использовать только существующий проект Vercel `book-compass-fantlab` и репозиторий `Belowskij/book-compass-fantlab`. Framework: Vite, сборка `npm run build`, выход `dist`, Node.js 24.x. Серверная функция из `api/` автоматически публикуется вместе с фронтендом. Все страницы используют URL-параметры в корневом пути; SPA-rewrite не нужен.

JSON-библиотека содержит `version: 1`, `exportedAt` и массив `items`. Размер импорта ограничен 5 МБ и 5000 книг. Импорт полностью проверяется перед изменением текущих записей.
